🚀 Getting Started
----------------------------------------------------------------------------------
1. Clone the Repository with as:
git clone https://github.com/your-username/your-repository-name.git

2. Open the Project:
Open the project in your preferred IDE, such as:
IntelliJ IDEA
Eclipse
VS Code

3. Build the Project:
Using Maven Wrapper:
mvnw.cmd clean install  (For Window)
./mvnw clean install (Linux / macOS)

4. Run the Application
You can run the application from:
PracticesApplication.java *

or using Maven:
./mvnw spring-boot:run  *

On Windows:On Windows:
mvnw.cmd spring-boot:run  *


🧪 Testing
---------------------------------------------------------------------------------
The project contains a test structure under:
src/test/java/com/security/practices  *

Tests can be executed using:
./mvnw test  *

For Windows:
mvnw.cmd test  *
